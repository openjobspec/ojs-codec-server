# Contributor Covenant Code of Conduct

This project has adopted the [Contributor Covenant Code of Conduct, version
2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

We pledge to make participation in this community a harassment-free,
welcoming experience. Be respectful, accept constructive feedback, and focus
on what is best for the community.

Report unacceptable behavior confidentially to
[conduct@openjobspec.org](mailto:conduct@openjobspec.org). Project maintainers
will review reports promptly and fairly.
